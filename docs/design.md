# Визуальный стиль Sakuya

Официальная палитра задана пользователем по четырём изображениям персонажа:
тёплая слоновая кость, шампань, золото, янтарь, мягкий персиковый и тёмный
коричнево-чёрный цвет одежды. Значения ниже адаптированы для читаемого интерфейса.

| Переменная CSS | Цвет | Назначение |
| --- | --- | --- |
| `--color-background` | `#FFF9EE` | Основной фон, слоновая кость |
| `--color-surface` | `#FFFDF8` | Светлые карточки и поля |
| `--color-surface-soft` | `#F4E5CF` | Шампань, второстепенные поверхности |
| `--color-border` | `#DCC3A0` | Разделители и границы |
| `--color-gold` | `#D6A24D` | Золотые кнопки, выбранные элементы, украшения |
| `--color-gold-deep` | `#8A591F` | Читаемый золотистый текст и ссылки |
| `--color-amber` | `#F2C66D` | Янтарные блики и подсветка |
| `--color-peach` | `#EBC0A8` | Мягкие второстепенные акценты |
| `--color-text` | `#2B211C` | Основной текст, тёмные элементы |
| `--color-text-muted` | `#715D4E` | Второстепенный текст |

Основную площадь интерфейса занимают светлые тёплые поверхности. Золото выделяет
действия и активные элементы, янтарь добавляется небольшими световыми акцентами.
Тёмный оттенок используется для текста и контрастных деталей. Персиковый — мягкое
дополнение в духе изображений персонажа.

Для текста на светлом фоне используются `--color-text`, `--color-text-muted`
и `--color-gold-deep`. На золотой кнопке используется `--color-text`;
для светлого текста подходит фон `--color-gold-deep`.

Текущие CSS-переменные определены в `:root` файла `app/app.css`.
Новые страницы и модули используют эту общую палитру. Семантические цвета
успеха, предупреждений и ошибок сохраняют своё значение и не меняют фирменную палитру.
